=== SLIDE 3 ===
  [AUTO_SHAPE (1)] Introduction
  [PLACEHOLDER (14)] Abstract
  [AUTO_SHAPE (1)] Medical Representatives (MRs) are required to plan multiple doctor visits within limited working hours, where doctor priority, availability, visit duration, geographical distance and travel time make manual planning difficult. This project proposes an AI-based web application for visit prioritization and route optimization.
  [AUTO_SHAPE (1)] The system uses historical and operational data to estimate the priority of planned doctor visits using a Machine Learning model. The resulting priority information is combined with appointment time windows, visit duration, MR working hours and travel information. Google OR-Tools is then used to generate a feasible route using Vehicle Routing Problem with Time Windows (VRPTW) concepts.
  [AUTO_SHAPE (1)] The system provides role-based dashboards for Medical Representatives and managers, enabling data-driven visit planning, monitoring and analysis.
  [AUTO_SHAPE (1)] Keywords: Medical Representative, Machine Learning, Visit Prioritization, Route Optimization, VRPTW, Random Forest, Google OR-Tools
